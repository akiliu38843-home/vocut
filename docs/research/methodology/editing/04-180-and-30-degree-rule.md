# 180° 轴线律 + 30° 跳切律

**来源**：连续性剪辑 (Continuity Editing) 的两条最古老的硬规则，起源于 1910s 古典好莱坞
**参考链接**：
- [Wikipedia · 180-degree rule](https://en.wikipedia.org/wiki/180-degree_rule)
- [Wikipedia · 30-degree rule](https://en.wikipedia.org/wiki/30-degree_rule)
- [EditMentor · 180-Degree Rule](https://editmentor.com/blog/the-180-degree-rule-dont-cross-the-line/)
- [Backstage · Continuity Editing](https://www.backstage.com/magazine/article/continuity-editing-guide-75720/)

## 180° 轴线律 (The Line)

**规则**：两个角色之间画一条假想线 (轴线 / Line of Action)，**摄影机必须始终在这条线的同一侧**。

**为啥**：观众靠"左右关系"理解空间。一旦摄影机跳过线，角色 A 本来在左、突然跑到右 → 观众瞬间懵。

**大白话**：你跟朋友坐对面聊天，旁观者必须始终从同一边看你们俩。绕到背后看是允许的，但**不能突然从正面切到背面**。

**对 vocut**：vocut 是**版式动画 + B-roll**，没有"对话双人"，但**有同源问题**：
- 同一组数据，上一场景在左 (KeyNumber 左对齐) → 下一场景突然移到右 (KeyNumber 右对齐) = 跳轴
- 同一引语，上一场景作者在画面右侧 → 下一场景作者在画面左侧 = 跳轴

→ **vocut 需要"主体位置一致性"规则**：相邻 2-3 个场景中，同主题的视觉锚点应在同一侧。

## 30° 跳切律

**规则**：相邻两个镜头之间，摄影机角度**至少变 30°**，否则就是跳切 (jump cut)，观众感觉"卡了一下"。

**为啥**：< 30° 的小幅移动看起来不像是"换了视角"，看起来像"原镜头跳了一帧"，是技术失误感。

**大白话**：要换角度就大方换 (至少差 30°)，要不就别换 (保持原角度)。**最忌讳"换了一点点"**——看起来像视频卡顿。

**对 vocut**：vocut 是"组件切组件"不是"摄影机移摄影机"，但**有同源问题**：
- 上一段 KeyNumber "60亿" 居中大字 → 下一段 KeyNumber "120万" 也居中大字 = 跳切感 (只换数字，版式一样)
- 上一段 PullQuote 居中黑底白字 → 下一段 PullQuote 也居中黑底白字 = 跳切感

→ **vocut 需要"相邻场景版式必须显著差异"规则**：
连续 2 个 KeyNumber **必须**换版式 (大字居中 → 数字+折线对比 / 左对齐 → 右对齐 / 黑底 → 浅底)。
否则就是跳切感，观众觉得"内容相似得让我没动力看下去"。

## 何时**故意**违反

- **180° 跳轴**：故意制造迷惑、不安、冲突感 (《老男孩》《2001 太空漫游》都故意违反)
- **30° 跳切**：法国新浪潮 (戈达尔《筋疲力尽》) 故意用跳切制造存在主义焦虑

→ vocut 当前**不是故意违反，是不知道这两条规则存在**。

## 对 vocut 的转化

**新增 plan.py 规则**：`_check_visual_continuity(plan_items)` 应该在场景排好后扫一遍：

1. 相邻同组件类型的场景，要求 layout 变体不同 (左/中/右对齐至少切换一次)
2. 相邻同色板的场景 ≤ 3 段后必须换色板 (避免单调)
3. 相邻 PullQuote 必须换作者位置 (引言来源不能两段都在右下角)
