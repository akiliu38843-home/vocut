# Practical Typography — Matthew Butterick's key rules

Source: https://practicaltypography.com/summary-of-key-rules.html

## The 4 most important things for body text
> Point size · Line spacing · Line length · Font

## Sizes
- Point size: **10–12 pt in print, 15–25 px on screen**
- Line spacing: **120–145% of point size**
- Line length: **45–90 characters per line** (including spaces)

## Font choice
- "The easiest and most visible improvement is to **use a professional font**"
- **Avoid**: goofy fonts, monospaced fonts (for body), most free fonts, system fonts — especially Times New Roman and Arial
- Letterspacing: **5–12% extra** with all caps and small caps
- **Kerning always on**
- If you don't have real small caps, **don't use them at all**

## Punctuation / characters
- Use curly quotation marks `" "`, not straight `" "`
- Apostrophes point downward
- Foot/inch marks should be straight, not curly
- Make ellipses with the actual `…` character, not periods + spaces
- Use the actual `&` only sparingly, unless part of a proper name
- Proper trademark/copyright symbols, not alphabetic approximations
- Don't confuse hyphens and dashes; don't use multiple hyphens as a dash
- In a document longer than 3 pages: **one exclamation point is plenty**
- Put a nonbreaking space after paragraph and section marks

## Emphasis
- **Bold OR italic, sparingly**; never both together
- **Never underline**, except perhaps for web links
- All caps OK for **less than one line of text**
- Use centered text sparingly

## Spacing
- Put **only one space** between sentences
- Don't use multiple word spaces or other whitespace in a row
- First-line indent: 1–4× the point size, OR 4–10pt between paragraphs (not both)
- Use hyphenation with justified text
